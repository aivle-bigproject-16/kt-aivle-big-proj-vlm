# 일일 리포트 생성

카테고리: report
Method: POST
URL: /vlm/reports/daily
사용자: 백엔드
상태: 진행 중

### Request

| **Key** | **설명** | **타입** | **Nullable** | **관련 DB 테이블/컬럼   PDF** |  |
| --- | --- | --- | --- | --- | --- |
| `reportDate` | 리포트 기준일 (`YYYY-MM-DD`) | String | False | `reports_daily.report_date`  |  |

`summaryData` : 당일 통계 집계 데이터 메인 객체

| `totalCount` | 금일 수행된 총 검사 수 | Integer | False | `summary_json` -> `totalCount` |
| --- | --- | --- | --- | --- |
| `passCount` | 금일 양품(`PASS`) 판정 수 | Integer | False | `summary_json` -> `passCount` |
| `rejectCount` | 금일 불량(`REJECT`) 판정 수 | Integer | False | `summary_json` -> `rejectCount` |
| `failedCount` | 금일 시스템 오류 및 분석 실패 수 | Integer | False | `summary_json` -> `failedCount` |
| `prevTotalCount` | 전날 총 검사수 | Integer | False |  |
| `prevRejectCount` | 전날 총 불량수 | Integer | False |  |

`defects` :  결함 유형별 통계 목록 배열

| `defectType` | 결함 종류 코드 명칭 (예: `CRACK`) | String | False | `defects[]` -> `defectType` |
| --- | --- | --- | --- | --- |
| `count` | 해당 결함의 당일 누적 발생 건수 | Integer | False | `defects[]` -> `count` |

```json
{
  "reportDate": "2026-07-06",
  "summaryData": {
    "totalCount": 120,
    "passCount": 104,
    "rejectCount": 14,
    "failedCount": 2,
    "prevTotalCount": 12,
    "prevRejectCount": 4,
    "defects": [
      { "defectType": "MICRO_DEFECT", "count": 5 },
      { "defectType": "CRACK", "count": 2 }
    ]
  }
}
```

Qwen 모델에 이미지를 전달할때 마스킹 된 이미지를 전달할 것인가, 이미지와 bbox만 전달 할 것인가

→ 이미지와 bbox만 전달한다(가로 세로 0~ 1000 까지의 비율로 환산하여 보내주면 Qwen이 볼 수 잇음)

**Query parameter**

### Response

| **Key** | **타입** | **Nullable** | **설명** | **관련 DB 컬럼** |
| --- | --- | --- | --- | --- |
| `status` | String | False | 생성 결과 상태 (`COMPLETED` 또는 `FAILED`) | `reports_daily.status`  |
| `title` | String | True | LLM이 생성한 일일 보고서 제목 | `reports_daily.title`  |
| `content` | String | True | LLM이 종합 요약한 일일 공정 진단 보고서 본문 | `reports_daily.content`  |
| `failureReason` | String | True | `status`가 `FAILED`일 때의 상세 에러 사유 | `reports_daily.failure_reason`  |

**Example**

```jsx
{
  "status": "COMPLETED",
  "title": "2026-07-06 생산 라인 검사 종합 진단 리포트",
  "content": "### 금일 종합 진단\n2026년 07월 06일 가동된 생산 라인의 전체 검사 수는 120건입니다. 이 중 불량률은 약 11.6%로...",
  "failureReason": null
}
```

### Status

| status | response content |
| --- | --- |
| 200 | Accepted |
| 400 | Bad Request |
| 500 | Internal Error |
