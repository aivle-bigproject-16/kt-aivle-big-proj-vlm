# 개별 리포트 생성

카테고리: report
Method: POST
URL: /vlm/reports/individual
사용자: 백엔드
상태: 완료

### Request

| `cellSerialNo` | 셀 시리얼 넘버(외부 분류용) | str | False |  |
| --- | --- | --- | --- | --- |
| `inspectionId` | 검사 아이디 | int | False |  |
| `totalImages` | 검사한 총 이미지 수 | int | False |  |

`defectInfo` : 탐지된 결함 정보 배열

| `imageType` | 이미지 타입(CT 또는 RGB) | str | False |  |
| --- | --- | --- | --- | --- |
| `defectType` | 이미지 속 판별된 결함들 | List[str] | False |  |

**Example**

```json
{
	"cellSerialNo": "CELL-A92B-2026",
  "inspectionId": 84210,
  "totalImages": 12,
  "defectInfo": [
	   {"imageType": "CT", "defectType": ["MICRO_DEFECT"]},
     {"imageType": "RGB", "defectType": ["CRACK","SPOT"]},
     {"imageType": "RGB", "defectType": ["SPOT"]}
	]
}
```

**Query parameter**

### Response

| **Key** | **타입** | **Nullable** | **설명** | **관련 DB 컬럼** |
| --- | --- | --- | --- | --- |
| `status` | String | False | 생성 결과 상태 (`COMPLETED` 또는 `FAILED`) | `reports_individual.status`  |
| `title` | String | True | LLM이 추천/생성한 리포트 제목 | `reports_individual.title`  |
| `content` | String | True | LLM이 최종 생성한 리포트 상세 마크다운/텍스트 본문 | `reports_individual.content`  |
| `failureReason` | String | True | `status`가 `FAILED`일 때의 상세 에러 사유 | `reports_individual.failure_reason`  |

**Example**

```jsx
{
  "status": "COMPLETED",
  "title": "Cell BATT-2026-0706A 결함 정밀 분석 보고서",
  "content": "### 1. 결함 요약\n금일 발생한 배터리 셀(BATT-2026-0706A)의 퓨전 판정 결과는 REJECT입니다. ...",
  "failureReason": null
}
```

### Status

| status | response content |
| --- | --- |
| 200 | Accepted |
| 400 | Bad Request: |
| 500 | Internal Error |
