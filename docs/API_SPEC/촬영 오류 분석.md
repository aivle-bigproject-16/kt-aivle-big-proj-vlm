# 촬영 오류 분석 (이미지 품질 검사)

카테고리: inspection
Method: POST
URL: /vlm/qualityInspection
사용자: 백엔드
상태: 완료

### Request

| **Key** | **설명** | **타입** | **Nullable** |
| --- | --- | --- | --- |
| `imageType` | 검사할 이미지의 타입 (`CT` 또는 `RGB`) | String | False |

`images` : 품질 검사를 수행할 이미지 객체 배열

| **Key** | **설명** | **타입** | **Nullable** |
| --- | --- | --- | --- |
| `imageId` | 개별 이미지의 고유 식별자 | String | False |
| `imageUrl` | 검사할 이미지의 접근 가능한 URL 또는 로컬 경로 | String | False |

**Example**

```json
{
  "imageType": "RGB",
  "images": [
    {
      "imageId": "image1",
      "imageUrl": "[https://example.com/images/rgb_sample_01.jpg](https://example.com/images/rgb_sample_01.jpg)"
    },
    {
      "imageId": "image2",
      "imageUrl": "[https://example.com/images/rgb_sample_02.jpg](https://example.com/images/rgb_sample_02.jpg)"
    }
  ]
}
```

### Response

| **Key** | **타입** | **Nullable** | **설명** |
| --- | --- | --- | --- |
| `status` | String | False | 검사 결과 상태 (`COMPLETED` 또는 `FAILED`) |
| `content` | List[Dict] | True | 분석된 개별 이미지의 화질 불량 원인 및 설명 목록 |
| `failureReason` | String | True | `status`가 `FAILED`일 때의 상세 에러 사유 |

`content` 배열 내 개별 객체 명세:

| **Key** | **타입** | **설명** |
| --- | --- | --- |
| `imageId` | String | 요청 시 전달받은 이미지 고유 식별자 |
| `failType` | String | 판별된 실패 케이스 ID (예: `rgb_focus_failure`, `ct_acquisition_motion` 등) |
| `description` | String | 발견된 현상에 대한 시각적 근거 요약 (OpenCV 1차 검출인 경우 `[OpenCV 검출]` 머리말 포함) |

**Example**

```json
{
  "status": "COMPLETED",
  "content": [
    {
      "imageId": "image1",
      "failType": "rgb_focus_failure",
      "description": "[OpenCV 검출] 선명도 점수(1.1) 미달로 초점 불량."
    },
    {
      "imageId": "image2",
      "failType": "rgb_surface_dust",
      "description": "배터리 표면에 초점이 흐린 원형의 짙은 반점이 존재하며, 이는 먼지 그림자가 묻어 있는 것으로 판단됨."
    }
  ],
  "failureReason": null
}
```

### 💡 판별 기준 (Fail Types) Reference

**[CT 이미지 에러 케이스]**
*   `ct_NONE`: 결함이 전혀 없는 매끄럽고 선명한 정상 CT 영상
*   `ct_cell_alignment_failure`: [OpenCV] 배터리가 촬영 영역을 벗어나 외곽이 잘림
*   `ct_low_signal_noise`: [OpenCV] 평균 노이즈 수치 초과로 화질 저하
*   `ct_acquisition_motion`: 이중 윤곽선, 방향성 흐림 (Ghosting)
*   `ct_insufficient_projection_sampling`: 외곽선 알리어싱, 얕은 줄무늬(Streak) 발생
*   `ct_beam_hardening_metal_streak`: 고밀도 영역 중심의 명암 왜곡(Cupping), 강렬한 방사형 선

**[RGB 이미지 에러 케이스]**
*   `rgb_NONE`: 결함이 전혀 없는 매끄럽고 선명한 정상 RGB 영상
*   `rgb_focus_failure`: [OpenCV] 선명도 점수 미달로 초점 불량
*   `rgb_underexposure`: [OpenCV] 평균 밝기 미달로 노출 부족
*   `rgb_overexposure`: [OpenCV] 평균 밝기 초과로 노출 과다
*   `rgb_trigger_timing_failure`: 프레임 잘림, 배터리 상/하단 화면 밖 이탈
*   `rgb_uneven_lighting`: 심한 명암 그라데이션 및 조명 불균형
*   `rgb_reflection_glare`: 굵고 길다란 하얀색 정반사 빛기둥(Core)과 빛 번짐(Bloom)
*   `rgb_surface_dust`: 초점이 흐린 원형/타원형의 짙은 반점, 먼지 그림자
*   `rgb_hair_contamination`: 화면을 가로지르는 가늘고 구부러진 실오라기 선형 그림자
